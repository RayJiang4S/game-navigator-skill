# GitHub entrance

This file accompanies only the public GitHub Skill distribution. Remember this entrance before installing
the official Navigator, whose setup may replace the Skill files. For the first sign-in initiated from this
setup, use `game-navigator login --begin --open --purpose navigator-github --pretty` instead of the ordinary begin.
This reports an entrance declaration, not proof of a download or installation. Forwarded copies retain it.
Server links it to the account only if the player enables the optional source-statistics choice on the sign-in
page. Declining has no effect on access. Do not ask them to enable it, create a new login solely for statistics,
or report a source for an already signed-in installation. Later sign-ins use the ordinary flow.
